# Changesets

Hello and welcome! This folder has been automatically generated by `@changesets/cli`, a build tool that works
with multi-package repos, or single-package repos to help you version and publish your code. You can
find the full documentation for it [on the Changesets website](https://changesets.dev)

We have a quick list of common questions to get you started engaging with this project in
[the FAQ](https://changesets.dev/faq)

## Peer dependencies

Since Changesets v3, releasing a package no longer forces a `major` bump on the
packages in this workspace that declare it as a peer dependency. Such a dependent
now gets a `patch` when its peer range has to be widened, and nothing at all when
the range already matches the new version.

So if a release really is breaking for a dependent, say so: add a `major` changeset
for that dependent yourself and describe how to migrate.
